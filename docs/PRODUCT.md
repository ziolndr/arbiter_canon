# CANON product

## Positioning

**CANON**

**Ask scripture.**

Write a question, decision, fear, belief, or claim. CANON measures it against every passage in the Bible and returns the strongest ranked resonance.

**No generated answers. Only scripture.**

## Product boundary

CANON is not a Bible chatbot. It does not write sermons, summarize doctrine, invent explanations, or answer in a synthetic voice. It returns the scripture field itself.

## Included core

- Complete 66-book validated corpus pipeline
- Static verse, passage, and chapter indexes
- Dedicated local search process
- Testament and book filters
- Ranked top-50 field
- Strongest verse emphasis inside a passage
- Expandable passage structure
- Full chapter reading
- Local saved readings
- Local question history
- Native share/copy
- Permanent query cache

## Subscription shape

The core supports a clean `$20/month` plan boundary:

- unlimited searches
- complete top-50 field
- history and saved readings
- notes and collections
- exports and study sheets

Accounts, synchronized storage, notes, collections, exports, and Stripe belong in the hosted application layer after the immutable search core is deployed. They do not belong inside the scripture measurement engine.
